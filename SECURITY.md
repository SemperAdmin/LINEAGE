# Security

Please report suspected vulnerabilities privately through GitHub's
**Report a vulnerability** button on this repository's **Security** tab,
not in a public issue. Include what you found, where, and how to reproduce
it. You will get an acknowledgement, and a fix or an explanation, as soon as
practical.

This is a static site: it has no accounts and stores no user data on a
server. See the README for what, if anything, leaves the browser.
